# X10 Think

World-leading **x10 Thinking** web application.

Escape your Current View of the Situation (CVS) and search for a Better View (BVS).  
**CVS × 10 = BVS**

Core tool: **Do a GBB!** — generate 10 Good, 10 Bad, and 10 Better points on any idea, decision or situation.

## Expert Features Added

- Full GBB engine (client-side, editable, saveable)
- First Principles decomposition
- Six Thinking Hats overlay (de Bono)
- Inversion & Pre-mortem
- Decision Model scoring (inspired by 2026 System-1 models: Jev, Clef, Strands Decider, pplx-decider)
- Local session history + Markdown export
- Privacy-first (everything stays in the browser)
- Cloudflare Pages ready (static, no build step)

## Research Basis

Built on the work of Dr Michael Hewitt-Gleeson (School of Thinking) — cvs2bvs, tenpower, GBB.  
Enhanced with cutting-edge frameworks from 2026: AI decision models, second-brain tools, first-principles practice, and multi-perspective thinking systems.

## Deploy to Cloudflare Pages

1. Push this repo to GitHub (v2-prog/x10think)
2. In Cloudflare dashboard → Workers & Pages → Create application → Pages → Connect to Git
3. Select the repository
4. Framework preset: **None**
5. Build command: *(leave empty)*
6. Build output directory: `/`
7. Deploy

Every push to `main` will auto-deploy.

## Custom Domain

Point any Cloudflare domain (e.g. x10think.acerlab.link or a new one) at the Pages project.
